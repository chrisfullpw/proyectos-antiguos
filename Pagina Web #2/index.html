Capacitaciones

Administracion de base de datos

Manejo, mantenimiento, desempeño y confiabilidad de bases de datos. Asimismo, estamos a cargo de la mejora y diseño de nuevos modelos de las mismas.

Migracion de datos

La realización de la migración ayudara a mejorar en el funcionamiento, mejorar la seguridad y el control de la información.

Seguridad

Identificación de la sensibilidad, Evaluación de la vulnerabilidad y la configuración, Endurecimiento, Audite, Monitoreo, Pistas de Auditoría, Autenticación, control de acceso y Gestión de derechos

Limpieza de datos

La limpieza de datos nos permite identificar datos incompletos, incorrectos, inexactos y no pertinentes, luego substituir, modificar o eliminar estos datos sucios.

Economia

El sistema no tiene fines de lucro, podra ser utilizada en la sede sin ningun problema y los gestores haran sus respectivo seguimiento con el sistema.

Presupuesto

El sistema cambiara la modalidad de trabajo a la hora de anotar o colocar alguna informacion, el papel no sera indispensable.

Nuestra Finalidad

Queremos revolucionar los metodos de estudio actuales, una gran ayuda para los rectores, coordinadores, docentes y estudiantes.

Sabemos lo agobiante que puede ser no encontrar una aula, saber cual es el horario o evento del dia, registrar una nota en una hoja o en excel.

Si a la hora de inicio de sección se le olvido la contraseña, hay un apartado de ayuda para estas situaciones, donde mediante al correo le enviará un código de verificación y le dará la opción de colocar una nueva contraseña

Si dejo su inicio de sección activo en un ordenador ajeno, el sistema tiene un historial a la hora de hacer alguna modificación.

Si la página tiene un inconveniente a la hora de mostrar la información deseada, la página tiene un apartado de preguntas frecuentes, si ninguna de estas es la deseada puede contactarnos.

A la hora de colocar datos para el ingreso de la información, si los datos son erróneos le dirá (Error, los datos ingresados son erróneos), solo tendran tres intentos, si se agotaron los intentos y no pudo intresar los datos datos correctos, el sistema enviara al correo (Ya has utilizado los tres intentos de inicio de sección), si sigue el problema se notificara a los desarrolladores).

Manejo De Errores

El sistema brindara protección de los datos de: docentes, estudiantes, rectores, coordinadores y cargos administrativos, estos datos estarán protegidos, solo los rectores y coordinadores podrán modificar estos datos, cada uno de los roles tiene su apartado de inicio de sección, este sitio web tiene un sello de seguridad.
